SMART MEDICINE BOX - 1 HOUR DEMO

Run:
python -m pip install -r requirements.txt
python -m streamlit run app.py

Dashboard:
1. Click Generate 30-Day Demo Dataset.
2. Show SQLite-backed KPIs, trend, status chart, delay chart.
3. Show Random Forest AI risk table.
4. Paste your actual Tinkercad Serial output in the sidebar and click Save Tinkercad Run to SQLite.

Important: Tinkercad's browser Serial Monitor is not exposed as a normal COM port, so this demo uses structured import for actual Tinkercad runs. The database and ML logic are real; the 30-day training dataset is synthetic/simulated for demonstration.
